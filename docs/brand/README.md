# URML brand assets

| File | Use | Size |
|---|---|---|
| `urml-avatar.png` | GitHub organization avatar, social profile pictures | 1000 × 1000 |
| `urml-social-preview.png` | GitHub repository social preview (shown when the repo link is shared) | 1280 × 640 |
| `urml-mark-light-bg.svg` | Favicon and the mark on light backgrounds | vector |

The mark is five stacked bars, one per URML layer (L4 at the top, L0 at the bottom). The top bar is orange `#cc6b1f`; the other bars are bone `#faf7f1` on dark backgrounds or ink `#181715` on light ones, at 100%, 80%, 55% and 30% opacity. The bottom bar is shorter and thinner. Do not recolor or reorder the bars.

Site palette ("Robot Yellow"): ground `#0f0f0d`, accent `#f5c518`, pass/teal `#4fd1c5`. Type: Chakra Petch (display), Barlow (body), JetBrains Mono (code).
